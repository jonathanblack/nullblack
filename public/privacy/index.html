privacy

Effective November 18, 2026. Jonathan Black, doing business as nullblack.

This policy covers nullblack.com and the games listed below. It describes what we found in the code reviewed on November 18, 2026. It does not describe a store build, a native project, or a branch we did not open.

Contact: hello@nullblack.com.

This website

nullblack.com is a static site. These pages do not run analytics, advertising, or accounts. If you email us, we receive your address and whatever you write, and we use it to reply. The site code does not sell that mail.

Faded Maps

Reviewed in jonathanblack/fadedmaps: src/ui/save.ts, src/ui/ads-native.ts, template.html, and capacitor.config.ts.

  • On the device, localStorage key fadedmaps.journals.v1 holds daily and practice progress, campaign results, stats (played, solved, streak, best), and settings such as sound.
  • fadedmaps.sheets keeps a few generated puzzles so a phone does not rebuild them. Older dailies beyond about fourteen, and older cached sheets beyond a handful, are dropped on save.
  • The website loads Google AdSense, publisher ca-pub-1117832063249065, from pagead2.googlesyndication.com. One banner sits under the result sheet.
  • The iOS app (Capacitor, app id com.fadedmaps.game) uses Google AdMob for that same 320 by 50 banner, only while the result sheet is open. It requests Apple's tracking permission, then Google's consent form where Google marks one as required. The source comment says declining either still shows ads that are not personalized. The banner unit id is injected at build time.

We did not find an account, a cloud save, a leaderboard, a crash-reporting SDK, or a store billing SDK in the files we opened.

Sheerfall

Reviewed in jonathanblack/sheerfall: src/toys/fault/ads.ts, stats.ts, daily.ts, net.ts, and src/server/stats.ts.

  • On sheerfall.com the game loads Google AdSense H5 Games Ads for the same publisher id. It may show an interstitial after a finished run, and an optional rewarded ad to reroll a boon. Rewarded ads are not offered on the daily. The code does not load those ads on other hosts.
  • The game posts short event names (a visit, touch or desktop, ad events, and similar) to /api/event. Cloudflare D1 stores a count per UTC day and key. That table has no player id. The browser stores fl_seen and fl_first so a visitor is counted once a day. This runs only on sheerfall.com.
  • A leaderboard post, as defined in daily.ts, includes a device id, a display name you choose, score, wave, time, class, arena, and, for a daily, the date.
  • Online co-op sends your display name, class, and movement to a Cloudflare Durable Object room, which returns a rejoin token.

We did not open the file that first writes the leaderboard device id into storage, and we did not find a control that deletes a leaderboard row.

Cyberdeck: Runtime

Reviewed in jonathanblack/cyberdeck-runtime: scripts/managers/SaveManager.cs, web/src/ui/saveslot.ts, and web/src/engine/savecode.ts.

  • The Godot game writes one JSON file on the device at user://savegame.json, including progress and a saved-at time. New Game deletes that file.
  • The web build keeps a save in localStorage. A demo build uses a separate slot when the main slot holds a full-game save, so the demo does not overwrite it. You can export or import that save as a text code beginning with CDR1.

We did not find ads, accounts, analytics, or a crash-reporting SDK in the files we opened. We did not copy the exact localStorage key string out of the web main.ts.

Cyberdeck: Packet

Reviewed in jonathanblack/cyberdeck-packet, branch master: web/worker/account.ts and web/capacitor.config.ts. The repository's default branch did not contain that account file.

  • An optional account is a 10-character code, or an email. A 6-digit code is mailed from noreply@cyberdeckpacket.com through Cloudflare Email. The device keeps a random token.
  • Cloudflare D1 stores the email or code key, a hash of the device token, and the save document (up to about 900,000 characters). Sign-out deletes that device's token.
  • The iOS shell is Capacitor, app id com.cyberdeckpacket.game.

We did not find a route that deletes the account, the email, or the cloud save. We did not find an ads SDK or a store billing SDK in web/package.json.

Jurassic Legacy

Reviewed in jonathanblack/JurassicLegacy: src/save.ts, src/account.ts, src/leaderboard.ts, and worker/account.js.

  • localStorage key jurassic-legacy-save-v1 holds the expedition: lineage, traits, research, and similar game state. A daily calibration does not write that save.
  • An optional account uses an email plus a 6-digit code mailed from noreply@jurassiclegacy.com, or a 10-character link code. The device token is kept in jurassic-legacy-account.
  • Cloudflare D1 stores the email, a hash of the link code, a hash of the device token, and the save (up to 2 MB). It also stores hashed email codes and per-IP counters for rate limits. The IP is read from CF-Connecting-IP. Sign-out deletes the device row.
  • The daily leaderboard keeps a random player id, the name you chose, and an unsent result in this browser. It posts the id, name, score, and platform web to /api/daily.

We did not find a route that deletes the account, the email, or a leaderboard row. Lab "purchases" spend in-game DNA, not money. No ads SDK is listed in package.json.

Children

We did not find an age gate in the code we reviewed. nullblack does not knowingly collect personal information from children under 13. If you believe a child has sent us personal information, email hello@nullblack.com and ask us to delete it. Faded Maps and Sheerfall show ads. Whether any game is directed at children is not something the code states.

GDPR and CCPA

Where the law gives you the right, you can ask us to tell you what we hold, correct it, delete it, give you a copy, or stop selling or sharing personal information for cross-context advertising. We did not find code that sells personal information. Google may process device data when an ad runs, under Google's own policy. Email hello@nullblack.com with the game and, if you have one, the account email or link code. We do not charge for a request the law says is free, and we do not treat you worse for asking. We may refuse a request the law does not require.

Deletion

Clear the site's storage, or uninstall the app, to remove a local save.

For a Jurassic Legacy or Cyberdeck: Packet account, email hello@nullblack.com from the address on the account, or include the link code, and ask for deletion. Sign-out only drops that device's token. It does not delete the email or the cloud save. There is no in-game delete button in the code we read. Until there is one, email is the deletion path stores such as Google Play ask for.

Sheerfall's daily counters are not tied to a name. A leaderboard row is tied to a device id and a display name. Email us to ask for a row to be removed. We did not find a self-serve delete control.

Retention

Local data stays until you clear it. Faded Maps drops old daily sheets and extra cached puzzles as described above. Mailed sign-in codes expire after 15 minutes. We did not find a job that deletes old account rows, leaderboard rows, or Sheerfall's daily counters.
